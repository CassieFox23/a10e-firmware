# contributing

this is a finished write-up and a set of scripts, kept by one person as a hobby, so replies can take a while. issues are welcome. pull requests aren't expected.

## issues

- **something's wrong** in [`A10e-teardown.md`](A10e-teardown.md), the [hardware appendix](A10e-hardware-appendix.md), the README or a script in `tools/`: use the "something's wrong" form. say which file and section, what you think is wrong, and what you found instead. a build name, an address or offset and the command you ran make it easy to check. corrections are the most useful thing you can send, since the write-up was mostly done by an AI and reviewed in passes.
- **a question**: use the "question" form, and say which part you read first.
- **a security problem**: don't open an issue. see [SECURITY.md](SECURITY.md).

please don't attach Samsung firmware, extracted files or keys to an issue. name the build and where to look, and the maintainer can check it against their own download.

## pull requests

they aren't expected, since the write-up is done and the scripts are tied to one build. if you want to send a fix anyway, open an issue first so we can agree whether it fits.

by contributing you agree your work is released under the GPL-3.0, the same as the rest of the repo.

if an AI tool helped with an issue or a fix, [AI_POLICY.md](AI_POLICY.md) says what to tell us. the notes are a best guess, and [DISCLAIMER.md](DISCLAIMER.md) says what that means for flashing.

everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
